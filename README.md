# Premium Creative Personal Portfolio

A world-class, award-winning inspired personal portfolio website for **Barira** — exploring the intersection of **Data Science**, **Web Development**, and **Photography**.

Built with React, Vite, TypeScript, Tailwind CSS, Three.js, Framer Motion, and Lenis.

---

## 🌟 Highlights & Features

- **Cinematic Preloader**: Animated monogram, glowing neon progression bar, and seamless curtain transition with instant skip support.
- **Interactive 3D Hero Sculpture**: Bespoke Three.js WebGL centerpiece featuring a morphing iridescent Torus Knot, three concentric gyroscope rings (representing Data Science, Web Engineering, and Camera Optics), orbiting polyhedral satellites, and 1,400+ interactive quantum particles responding to mouse parallax.
- **Dynamic Role Switcher**: Animated rotation between *Data Scientist*, *Web Developer*, and *Photographer*.
- **Editorial About Section**: Interactive tri-facet tab system showcasing analytical and visual mindsets alongside custom editorial profile artwork.
- **Three Distinct Expertise Experiences**:
  - *Data Science*: Live animated regression chart and correlation metrics simulation.
  - *Web Engineering*: Interactive code editor window and live MERN queue simulator.
  - *Photography*: Interactive mirrorless camera viewfinder with live camera settings knobs.
- **Selected Works & Project Modals**: Showcase for all 5 signature projects with category filtering, card zoom, and rich architectural modals.
- **30 Days of Daily UI Showcase**: Complete 30-challenge design sprint gallery with batch navigation (Days 01–10, 11–20, 21–30), live search, category tagging, and interactive specification inspection.
- **Through My Lens (Photography Portfolio)**: Dynamic masonry gallery with category filters, hover metadata, and a full-screen interactive Lightbox supporting next/previous navigation, keyboard controls (Arrow keys / ESC), and camera EXIF parameters.
- **Leadership & Experience Timeline**: Vertical illuminated timeline highlighting roles across ICyDD 2026, JTECH 2026, JTECH 2025, and GDGoC.
- **Milestones & Recognition**: Animated certificate cards with interactive confetti triggers and document action links.
- **Contact & Inquiry System**: Validated contact form with mailto fallback and social links (LinkedIn, GitHub, Instagram).
- **Custom Follower Cursor**: Desktop trailing ring and precision dot that expands over interactive elements (automatically disabled on touch devices).
- **Smooth Inertial Scrolling**: Powered by Lenis with support for reduced-motion accessibility.

## 📁 Centralized Data Architecture

All content is separated from presentation logic in `src/data/` for effortless customization:

| File | Purpose |
|---|---|
| [`src/data/profile.ts`](src/data/profile.ts) | Personal bio, tagline, hero description, stats, and contact info |
| [`src/data/skills.ts`](src/data/skills.ts) | Core technical tools, proficiencies, and metrics for each discipline |
| [`src/data/projects.ts`](src/data/projects.ts) | Featured projects, descriptions, features, and technology tags |
| [`src/data/uiChallenges.ts`](src/data/uiChallenges.ts) | 30 Days of Daily UI challenges, categories, and tags |
| [`src/data/photography.ts`](src/data/photography.ts) | Photography gallery items, categories, captions, and EXIF metadata |
| [`src/data/experiences.ts`](src/data/experiences.ts) | Roles, organizations, dates, descriptions, and skills gained |
| [`src/data/achievements.ts`](src/data/achievements.ts) | Certificates, awards, and honors |

## 🚀 Getting Started

### 1. Development Server
Run the local Vite development server:
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 2. Production Build
Verify TypeScript and create an optimized production bundle:
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
